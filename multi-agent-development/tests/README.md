# 验证范围与用例

本目录不参与技能运行时的按需参考加载。修改技能时才读取。

## 静态检查

在技能目录执行：

```bash
python3 tests/test_package.py
```

该脚本只读真实交付文件，检查六字段头部、描述、技能包内相对链接、调用提示和用例结构；存在 ZCode 清单时也检查清单。它不执行模型、插件、浏览器操作或自动触发。DSH 市场不分发隐藏清单，因此安装副本的清单检查会明确跳过。

## 场景验证

[cases.json](cases.json) 提供实施授权、近邻负例、外部异步等待、未知状态、故障降级、取消未停止、只读边界和实机验收不可用等用例。

- 显式加载技能后讨论用例，只能算文档场景推演。
- 要验证真实行为，在隔离任务中执行，并保存工具事件、实际修改、退出结果和验收证据。
- 要验证自动触发，不能事先显式加载技能；应在目标宿主以相同用户请求观察真实技能选择事件。
- 失败、基础设施错误、权限拒绝和缺失日志分别记录；不得把“模型说会这样做”标成实际行为通过。
- 用例的 `verification` 初始为 `not_run`，结构测试不会改写状态。记录结果时附执行环境与证据，不把静态检查结果写回为行为通过。

这套测试没有证明不同模型的能力排名、速度改善或实时后台状态 UI 已修复。
