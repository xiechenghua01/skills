## 使用约定

主经验包是当前合并结论；历史材料中的固定数值、平台字段和检查承诺不自动成为通用规范。
静态阅读、文档校验、真实执行和目标宿主触发是不同证据，不互相替代。
实际技能入口仍是仓库 `skill-development/SKILL.md`，本目录不是可安装技能，不应当整包作为每次开发必读上下文。
本次按范围不更改 docs 外的历史路径文字；若旧说明提到根 docs 下的 playbook，现从本入口定位归档。
