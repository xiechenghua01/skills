# 条目模板

`generate.md` Step 2 搭骨架从这里复制。尖括号与行内注释是填写说明，**交付前全部删掉**。

契约（字段取值、五章判据、追加章节编号）见 [skeleton.md](skeleton.md)，本文件不重复。

```markdown
---
title: <概念名——必须是概念本身，不能是来源>
kind: entry                  # entry 条目式 / system 成体系
applies_to: universal        # universal 不随版本变化 / 具体范围如 MySQL 8.0+ / unknown 未确认
status: seedling             # seedling 粗糙 / budding 可链接 / evergreen 可复用
verified: none               # all 每条查过 / partial 部分查过 / none 未查
created: <YYYY-MM-DD>        # 实际当天日期，不要照抄
updated: <YYYY-MM-DD>        # 必须 ≥ created；每次修订更新
tags: [<标签1>, <标签2>]      # 与正文术语一致
---
```

## 追加章节（按需，不预埋）

放在五章之后，从 `6.` 接续编号：

```markdown
## 6. 常见疑问

### 6.1 <问题>

<答>

## 7. 延伸

- 要深入 <X>，读 <Y>：<一句话说明能解决什么>
```

## 成体系文档（`kind: system`）

结构自定，编号受两条约束：H2 用 `一、二、三、` 连续不跳号；H3 用 `x.y`，x 是父章的阿拉伯序号。

```markdown
---
title: <领域或主题名>
kind: system
applies_to: <universal 或具体范围>
status: seedling
verified: none
created: <YYYY-MM-DD>
updated: <YYYY-MM-DD>
tags: [<标签>]
---

# <领域或主题名>

<导语一段：定位、覆盖范围、结构总览>

## 一、<章节名>

### 1.1 <子节>

## 二、<章节名>
```
