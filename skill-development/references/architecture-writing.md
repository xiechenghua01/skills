# 架构与写法

新建时选最小结构，编辑时判断规则归属，理解时用本文件解释设计。不要把样本配额变成通用要求。

## 1. 按变化原因分层

| 层 | 职责 | 典型内容 | 不应承担 |
|---|---|---|---|
| 入口 | 触发与任务路由 | description、分支与共同边界 | 全部参数和领域知识 |
| 流程 | 输入、顺序、门槛、失败、结束 | create/edit/understand | 大段重复参考正文 |
| 参考 | 共同契约、领域知识、例外和模板 | references | 反向编排所有流程 |
| 执行 | 确定性解析、转换、校验和适配 | scripts | 未编码的业务判断 |
| 验证 | 用例、fixtures、断言与结果 | tests/evals | 冒充运行时能力 |
| 分发 | 宿主注册、版本、许可与展示 | manifest/market | 业务流程正文 |

简单技能从 SKILL.md 开始；出现真实分支、重复规则或稳定脚本后再拆分。
文件变多会产生断链和规则漂移，必须让每个文件有明确读取者和读取条件。
运行日志、基准结果和私有 fixtures 不默认加载给使用技能的 agent。

## 2. 按用户意图路由

用户通常说“新建、解释、修改”，不会说“进入 parser 模块”。路由使用用户能表达的意图和对象。
列出典型原话与近邻反例：每句应有清楚归属；复合任务可以顺序执行，不能为表格互斥而拒绝真实请求。
只读和写入有不同副作用，应明确分开。没有真实分支时不要机械套三链。

入口 description 同时写能力、触发情境与非目标；不用宽泛的“处理文件”“帮助开发”抢占普通任务。
触发元数据随宿主而异。显式加载验证只能证明正文可执行，不能证明模型会自动选择。

## 3. 渐进披露

入口短是为了减少无关规则，不是固定行数竞赛。每条流程指明何时读取哪些参考和何时停止。
用到一个组件或工具才读对应文档/schema；足以完成当前任务时停止加载。
共同的安全与证据边界可留在入口，不能为了“极薄”把所有人都需要的规则藏到不可达文件。

每个参考文件应能回答：谁在什么阶段读、解决什么选择、什么时候不读。
发布前检查相对链接、脚本路径与模块可达性；文件存在不等于会被路由到。

## 4. 规则写法

一条高价值规则至少消除一次真实选择的不确定性。按需包含触发条件、动作、对象、判据和失败处理。

| 空话 | 可执行改写 |
|---|---|
| 充分理解需求 | 写入前核对目标和范围；未知时只阻止相关写入 |
| 正确调用工具 | 读取当前 schema，核对必填、类型、单位、索引和对象身份 |
| 保证可信 | 数字带来源/时间/单位；无来源就标未知，不造替代值 |
| 输出简洁 | 删除不改变结论的流程旁白，保留证据、条件和不确定性 |

数值化适合尺寸、次数、枚举和协议；语义质量不应为可机检而制造虚假阈值。
正例约束目标，反例揭示具体失败；替代动作告诉 agent 失败后怎么继续。
禁令解释风险并限定适用条件。通篇 ALWAYS/NEVER 往往意味着缺少分层和理由。

删句检查：删除后行为、约束、输出和验收都不变，优先删除。
替换对象检查：换成另一行业仍处处成立，通常缺少当前任务的具体信息。

## 5. 需求与未知

需求状态和完成口径见 [contracts.md](contracts.md)。完整需求直接执行；缺失可逆实现细节可采用说明过的默认。
不要把固定提问数量当安全边界，也不要把“意图未完全对齐”扩大成所有动作停摆。
业务含义、对象、授权或费用不清时，只暂停依赖它们的动作。

复杂生成可用中间产物固化目标、证据和单元；只有后续步骤确实消费时才创建。
字段要有消费者和检查方式，不以固定 6–12 个字段作为质量标准。
允许 unknown、blocked、not_run；没有这些合法出口，模型会用猜测填空。

## 6. 脚本和状态

稳定重复且可确定的工作封装脚本；如果每个用例都临时写同一种程序，应纳入技能。
脚本输出区分成功、失败和不完整；错误不吞掉，退出码与结构化结果一致，stdout/stderr 按调用方约定。
测试调用交付实现，不另写一份自洽的复刻逻辑。

文件路径、内存实例、远端对象和用户视图是不同身份；使用真实稳定 ID，不从显示顺序或文件名猜对象。
写入超时先查状态。重试只能用于可安全重复的动作；资源清理限于本次创建 ledger，不做全局删除。

## 7. 沟通与结束

面向用户描述任务进展和产物，内部名称只在排错或用户需要时出现；不能以“说人话”为由隐瞒失败。
完成后停止无关优化。发生变更、检查覆盖不足或新证据出现时，验证受影响范围；这不属于无意义复检。
安装、提交、推送、发布和生产执行是独立副作用，开发请求不自动包含。
